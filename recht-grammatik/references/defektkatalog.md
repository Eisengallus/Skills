# Defektkatalog

Jeder Typ mit den zwei Lesarten, die er erzeugt, dem Merkmal, an dem die Auflösungsprobe ihn als
aufgelöst erkennt, und dem sprachlichen Mittel, das ihn schließt. Ein Typ ist kein Befund: Befund
ist eine Stelle erst, wenn sie die Befundschwelle der `SKILL.md` übersteht. Die Einzelheiten
stehen in der Referenz, die jede Gruppe nennt.

## Anwendung

- **Mehrere Stellen.** Jede Stelle eine Zeile, auch wenn dieselbe Bauform wiederkehrt. Treffen an
  einer Stelle zwei Typen zusammen (Bedingung an einer Reihe und fehlendes Komma), eine Zeile mit
  beiden Kürzeln.
- **Transaktionsklauseln** (Unternehmenskauf) haben keine eigenen Typen; die Typen treffen dort
  Garantien, Freistellungen, Vollzugsbedingungen, Höchstbeträge und Nachhaftung. Häufige Orte:
  der Zeitpunkt einer Garantie an einer Reihe von Stichtagen (RW-1, FR-5); ein Kenntnisvorbehalt
  vor einer Reihe von Garantien (RW-4); eine Zustandsaussage ohne einleitendes „garantiert“ (MO-6);
  ein Relativsatz hinter „Ansprüche Dritter und Verluste“ (RW-1, AN-1); „je Fall“ oder
  „insgesamt“ beim Höchstbetrag (RW-9); eine Ausnahme vom Höchstbetrag über eine Reihe (RW-2);
  der Beginn einer Ausschlussfrist „ab Vollzug“ oder „ab Kenntnis“ (FR-2, FR-3). Ob ein Ereignis
  „wesentlich“ nachteilig ist, ist eine Begriffsfrage — `[→ recht-logik]`.
- **Modus `norm`.** Fehlen der Verpflichtete einer Leistungs- oder Handlungspflicht (MO-4), der
  Fristbeginn (FR-2), die Tagesart (FR-4) oder der Handelnde einer vorangestellten Handlungsgruppe
  (SN-2), ist das dort ein Formdefekt, auch ohne Kandidaten im Text; `kritisch` nur, wenn zwei
  Beteiligte als Verpflichtete in Betracht kommen. Abhilfe mit Platzhalter.
- **Nur ein Flag.** Ist eine Frage keine des Wortlauts, ist das Flag die ganze Antwort auf sie;
  trägt der Text sonst keine Stelle, bleibt die Tabelle leer. Solche Fragen sind: ein offener
  Oberbegriff oder eine Regelungslücke (fehlender Fall oder Zweig) — `[→ recht-logik]`; der Inhalt einer Vorschrift, auf die der Text verweist —
  `[prüfen: Norm]`; die Folge einer Unklarheit in einer Formularklausel — `[→ recht-agb]`. Die
  Unklarheit selbst bleibt ein Befund dieses Skills.
